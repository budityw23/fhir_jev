   `/` Overview, `/studio/:module`, `/playground`, `/pipeline`, `/benchmarks`. Each page is a **placeholder**: a

   "Coming in D4" (Benchmarks).
   - Keep every emitted file in `web/dist` **under 1 MB** (sourcemaps excepted). Split heavy libraries (CodeMirror,
     Recharts) into separate chunks with `build.rollupOptions.output.manualChunks` and/or lazy-loaded routes.
3. **API types and client** (Step 3):
   - `scripts/dump_openapi.py`:
     - Default: write `web/openapi.json` from `create_app(Settings(mock_jev=True, demo_enabled=True)).openapi()`,
       with `json.dumps(..., indent=2, sort_keys=True)` plus a trailing newline, so it's deterministic.
     - `--samples`: write `web/src/test/fixtures/compare_{quality,router,notifiable}.json` by running
       `Comparer.compare` with `MockJevClient` on `tests/fixtures/patients/complete_patient.json` (quality),
       `tests/fixtures/bundles/mixed_bundle.json` with `route_confidence_minimum=0.99` (router), and
       `tests/fixtures/conditions/japanese_encephalitis_a83.json` (notifiable), each sent with its `fixture_id`.
     - **Make the samples deterministic:** replace volatile values (every `latency_ms`, the AuditEvent
       `recorded`, and any other timestamp) with fixed values, so re-running produces byte-identical files.
     - Docstrings, type hints; `ruff check scripts` and `mypy --strict scripts/dump_openapi.py` clean.
   - `web/src/api/schema.d.ts` generated by `npm run types` (openapi-typescript 7) and committed.
   - `web/src/api/types.ts`: re-export named types from `components["schemas"]` (`CompareResponse`, `FixtureEntry`,
     `DemoConfig`, `Thresholds`, `DecisionEvent`, `BenchmarkSummary`, …). **No hand-written duplicates of backend
     models.** Two exceptions only, because the backend doesn't export them in OpenAPI:
     `ErrorBody { error: string; detail: string | null; request_id: string; timestamp: string }` and
     `Health { status: string; jev_client: "mock" | "live"; jev_model: string | null; version: string }`. Put them
     in `types.ts` with a comment saying why.
   - `web/src/api/client.ts` exactly per Step 3: `ApiError(status, body, requestId)`, `api<T>(path, init?)`
     (JSON; throws `ApiError` on non-2xx, parsing the ErrorResponse body when present), and `LastRequest` plus
     `subscribeLastRequest(cb)`, which receives `X-Request-Id` and `X-Request-Duration-Ms` from every response.
   - `web/src/api/queries.ts`: `useHealth()` (refetch every 10 s), `useDemoConfig()`, `useFixtures(filters)`,
     `useFixture(id)`, `useCompare(module, input)`. `useCompare` is a `useQuery` keyed
     `[module, fixtureId ?? stableHash(resource), thresholds]` with `placeholderData: keepPreviousData`; POST
     `/api/v1/demo/compare/{module}`.
